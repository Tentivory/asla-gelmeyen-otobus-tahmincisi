# Asla Gelmeyen Otobüs Tahmincisi

## Resmi Duyuru

Bu yazılım, Türkiye Cumhuriyeti durak ekosisteminde gözlemlenen evrensel bir doğa yasasını kodlar:

**Otobüs her zaman 5 dakika sonradır.**

Eğer 5 dakika geçerse otobüs yine 5 dakika sonradır. Bu bir bug değildir. Bu fiziktir.

## Kurulum

```bash
python3 asla_gelmeyen_otobus.py
```

Bağımlılık yoktur. Sadece sabır gerekir. Sabır da yoktur.
